# Security

[Back to README](../README.md)

mcsync is designed for a small group of people who trust each other, on a private network. This page describes what it protects and what it expects from you.

## Network exposure

- `mcsyncd` listens only on the private address you pass to `--listen`. Addresses such as `0.0.0.0`, an empty host, or a host name are rejected, so the service cannot be exposed on every interface by mistake.
- No port needs to be opened on your router. Use a private network such as [Tailscale](https://tailscale.com) or any equivalent VPN.
- The service speaks plain HTTP and relies on the private network for transport security.

## Devices and tokens

- Every PC enrolls with a **single-use invite** that expires after 24 hours and gives the PC its own token.
- Tokens are tied to a device, not to a player: a lost or compromised PC can be revoked with `mcsyncd revoke` without affecting other devices of the same player.
- The server stores only hashes of invite secrets and tokens.
- The device token on a player's PC is stored in a file readable only by its owner.
- The player's identity is always derived from the token, never from the contents of a request, so a client cannot act on behalf of someone else.
- Invites and revocations can only be made on the always-on machine.

## Protocol safety

- Every request carries the protocol version. An incompatible client is rejected with a clear message before it can touch any data.
- Uploads are validated before they reach the archive: structure, size and file-count limits, and an integrity check.

## Data protection

- The archive is a restic repository, encrypted with a key generated by `mcsyncd init`.
- **The key is the single point of failure.** If it is lost, saved worlds cannot be recovered. Store a copy outside the always-on machine.
- The always-on machine holds the only official copy of the world. See [Backups](deployment.md#backups).

## Minecraft server

- Running the Minecraft server with `online-mode=true` is recommended, so that only genuine accounts can join.
- mcsync controls the server through its standard input. RCON is not used and no extra port is opened.
